# CryptoLab 🔐

My first Python cybersecurity project.

## Features

1. Caesar Cipher Encryption
2. Caesar Cipher Decryption
3. SHA-256 Hash Generation
4. SHA-256 Hash Verification

## Technologies Used

- Python 3
- hashlib
- Linux (Kali Linux via WSL)

## How to Run

python3 main.py

## Purpose

This project was created to understand
basic cryptography and Python programming.

## Disclaimer

Caesar Cipher is an educational algorithm
and is not suitable for real-world security.
